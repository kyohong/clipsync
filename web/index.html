📖 使用指南

💻 电脑端：如何接收

主力电脑（极致无感）

安装 Chrome 扩展并配置好相同 Worker 与配对码。手机无论何时敲击发送，电脑任意软件中直接按 Ctrl+V（Mac 按 Cmd+V）即可贴出内容，无需切换窗口。

临时设备（免插件纯网页）

受限或公用电脑直接打开本网页并保持在线。手机投送后，本页「实时接收记录」卡片会毫秒级跳出，点击卡片右上角的【一键复制】即可。

📱 手机端：如何发送

方式 A：通用网页直接发（免配置）

任何手机浏览器打开本页，点击“一键读取本机剪贴板并发送”大按钮（或手动粘贴），即可秒级推送到所有已配对设备。

方式 B：iPhone 极致体验（轻点背面）

iOS 打开「快捷指令」App ➔ 新建指令 ➔ 添加「获取剪贴板」➔ 添加「获取 URL 的内容」：

POST: https://你的Worker地址/send?room=配对码
Body: JSON { "text": 剪贴板 }

前往 iPhone 设置 ➔ 辅助功能 ➔ 触控 ➔ 轻点背面 ➔ 绑定此指令，敲击两下即刻发送。

方式 C：Android 安卓手机快捷发送

1. 浏览器打开本页，点击菜单选择「添加到主屏幕」，形成原生 App 体验。
2. 推荐配合免费开源 App「HTTP Shortcuts」：配置 POST 接口读取系统变量 {clipboard}，并将其添加至顶部下拉通知栏的控制中心磁贴（Quick Settings Tile），长按复制后下拉一点即发。
